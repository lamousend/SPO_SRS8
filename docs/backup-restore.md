# Резервная копия и восстановление

Скрипт scripts/backup_restore.py сохраняет данные в файл, проверяет копию и загружает ее обратно.
База выбирается как обычно: если задан DATABASE_URL - PostgreSQL, если нет - локальная SQLite.

| Команда | Что делает |
|---------|------------|
| backup [файл.json] | сохраняет копию (по умолчанию в папку backups/) |
| verify файл.json | загружает копию во временную пустую базу и проверяет ее; рабочая база не меняется |
| restore файл.json | загружает копию в пустую базу после migrate и проверяет; в непустую - только с --force |
| check [файл.json] | проверяет текущую базу: число записей и правильность остатков |

Что проверяется:

- остаток оборудования плюс выданное количество равны общему количеству;
- у каждого бронирования есть нужные события в истории;
- удалено может быть только бронирование в состоянии created.

## Что попадает в копию

Пользователи (с хэшами паролей), справочники, заявки, бронирования, история и журнал. Копия всегда
в кодировке UTF-8, поэтому ее можно переносить между Windows, Linux и macOS. Папка backups/ не попадает
в Git: файл копии нельзя публиковать и прикладывать к отчету.

## Копия и ее проверка

```bash
python scripts/backup_restore.py backup backups/demo.json
python scripts/backup_restore.py verify backups/demo.json
```

В конце должно быть ПРОВЕРКА ПРОЙДЕНА.

## Восстановление после потери базы

1. Создайте пустую базу: удалите испорченный db.sqlite3 и выполните python manage.py migrate.
2. python scripts/backup_restore.py restore backups/demo.json
3. Войдите на сайт и проверьте бронирования и остатки.

## Перенос SQLite в PostgreSQL

```bash
python scripts/backup_restore.py backup backups/transfer.json
export DATABASE_URL='<External Database URL>'      # Windows: $env:DATABASE_URL = "..."
python manage.py migrate
python scripts/backup_restore.py restore backups/transfer.json
```

После переноса новые записи создаются без ошибок, пароли пользователей прежние.

## Защита от ошибок

| Ситуация | Что произойдет |
|----------|----------------|
| restore в базу с данными | отказ, нужен --force |
| в базе нет таблиц | сообщение выполнить migrate |
| копия испорчена | ПРОВЕРКА НЕ ПРОЙДЕНА и код возврата 1 |

## Результат проверки

На Windows: check подтвердил правильность остатков, backup сохранил 24 объекта, verify загрузил копию
во временную базу, число записей совпало. Перенос в PostgreSQL 16
проверяется в CI ([ci-and-releases.md](ci-and-releases.md)).
